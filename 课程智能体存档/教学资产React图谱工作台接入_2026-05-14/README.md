# 教学资产 React 图谱工作台接入留痕

## 目标
将用户提供的 React + Tailwind 单文件组件思路接入当前静态项目，作为“教学资产”页面版本：保留路由和顶部导航，替换页面主体为“管理学原理课程图谱”工作台。

## 关键约束
- 中心图谱固定为“管理学原理课程图谱”。
- SWOT 只作为“计划与决策”模块下的示例节点，不作为教学实践或教学资产模块默认主题。
- 四周面板保留并随节点点击同步：当前节点概览、模块边界说明、课程资产统计 / 质量诊断、建议动作 / 快捷操作。
- 390px 移动端宽度下无横向滚动。

## 改动范围
- `前端核心/assets.html`
- `前端核心/app.js`
- `前端核心/styles.css`
- `tsconfig.json`

## 回滚方式
从本目录 `before/` 复制对应文件覆盖项目同名文件，然后重新运行：

```bash
node --check 前端核心/app.js
npm run build:static
npm run build:server
```
