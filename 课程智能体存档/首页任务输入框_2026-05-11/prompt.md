# 首页任务输入框改造

## 用户反馈
- 用户认可“首页首屏任务输入框”的方向，希望在 index 页 slogan 下加入一个入口，用一句话发起教学任务。

## 本轮目标
- 在首页首屏 slogan/说明文案下新增教学任务输入框。
- 输入框不命名为通用 ChatGPT 聊天，不新增聊天页；语义定位为“教师发起教学任务”。
- 根据任务语义进入现有三页主线：教学导航、教学实践、教学资产。
- 保存本轮改造前后代码、prompt、修改日志和检查结果，并提交推送到 GitHub。

## 边界
- 不新增后端接口。
- 不接入真实大模型聊天。
- 不破坏现有首页 Agent 工作台演示和三页导航。
