# 用户反馈

用户认为当前首页 Cowork 式演示效果不如其提供的 React/Tailwind 样稿。

# 本轮目标

在保持静态 HTML/CSS/JS 架构的前提下，把首页三功能演示区进一步向用户样稿靠拢：增强首屏视觉比例、深色左侧输入面板、右侧浅色 Output Preview、三功能 Tab、附件 hover/focus 联动高亮与整体空间层次。

# 约束

- 不引入 React、Tailwind 或新构建框架。
- 不改变既有导航、登录/注册、主 CTA 路径。
- 只修改首页相关源码：前端核心/index.html、前端核心/app.js、前端核心/styles.css、package.json 如有必要。
- 本轮先留痕，再改造，再检查，再提交推送 GitHub。
