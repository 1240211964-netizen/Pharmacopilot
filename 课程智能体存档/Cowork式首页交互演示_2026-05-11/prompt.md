# Prompt

用户要求执行计划：

> 首页三功能 Cowork 式交互演示区改造计划

执行理解：

- 将用户提供的 React/Cowork 交互范式迁移到现有静态首页。
- 保持静态 HTML/CSS/JS 架构，不引入 React、Tailwind 或新构建框架。
- 首页形成“教学导航 / 教学实践 / 教学资产”三任务切换演示区。
- 左侧呈现 Prompt、Attachments、Agent Activity，右侧呈现 Output Preview。
- 附件 hover/focus 联动右侧输出高亮。
- 留痕包含 before/after 代码、prompt、修改日志、构建检查、浏览器检查，并提交推送 GitHub。
