# Browser Checks

本轮通过本地静态服务检查：`http://127.0.0.1:4177/teaching-navigation.html`。

## Desktop

- 页面可打开，标题为 `Pharmacopilot | 教学导航`。
- 20 个地图节点完整渲染。
- 3 个阶段 pill 完整渲染。
- 点击阶段二 pill 可定位到节点 09，并打开右侧说明态卡片。
- 点击节点 01 后默认显示说明态，包含“为什么存在 / 需要输入什么 / 生成什么 / 如何合格”，且不直接显示方案选择区。
- 点击“开始本环节训练”后显示方案选择区、智能生成草稿、评价诊断和确认入口。
- 点击“确认本环节”后节点推进到节点 02，统计更新为已完成 1、进行中 1、可进入 2、待解锁 16。

## Locked Node

- 已通过阶段 pill 入口验证锁定节点可进入说明态。
- 锁定节点训练按钮文案为“完成前序节点后开始训练”，按钮禁用。

## Responsive

- 使用本地 Chrome headless 进行桌面与移动视口检查。
- 移动端补充修复了首页标题换行、状态卡文本和阶段卡文本的窄屏溢出风险。
- 留痕以 before/after 代码、prompt、变更日志和检查记录为准，不依赖截图。

## Notes

- 内置浏览器不允许直接访问 `file://`，因此改用本地 HTTP 静态服务检查同一工作区文件。
- Chrome headless 输出了 GPU shared image 警告，但截图文件正常生成，不影响本轮构建与交互验证。
