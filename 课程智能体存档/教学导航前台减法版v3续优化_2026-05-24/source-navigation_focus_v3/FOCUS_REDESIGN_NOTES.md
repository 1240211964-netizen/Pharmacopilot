# PharmacoPilot 教学导航前台减法版 v3

## 改造判断

当前页面的问题不是三时段十任务站结构错误，而是后台解释被过度前台化。用户进入教学导航页时，只需要完成当前站点的教学判断；理论依据、后台检查点、质量雷达、证据链审计、运行状态和完整资产货架不应同时压到主界面。

## 前台保留

1. 三时段路线：课前设计与准备、课中实施与调控、课后评价与改进。
2. 十个任务站短导航。
3. 当前任务站：只显示一句用户任务。
4. 药事管理情境：压缩为一个 select，不再展示四张大卡。
5. 一图一题：证据图 + 教学判断题。
6. 系统反馈：仅在用户选择后出现。
7. 产物生成：默认折叠，生成后可展开编辑。
8. 保存资产与下一站按钮。

## 前台移除或折叠

1. what / why / how 全量说明：折叠到“本站依据”。
2. 质量雷达：移出首屏，后续可放到详情抽屉或教学数据页。
3. agent 运行状态：不放前台，除非出现错误。
4. 产物审校预览：与产物编辑合并。
5. 证据链卡片：不在主页面常驻，保存资产后进入教学数据页。
6. 资产货架：不常驻展示，只在进度数字中反馈。

## Codex 执行原则

- 不要把后台说明重新放回主界面。
- 不要把页面做成 dashboard。
- 每个任务站只让用户完成一个判断。
- 图表是主输入，判断题是主交互，产物是主输出。
- contract 文件保留完整结构，但 UI 只取当下必要字段。
