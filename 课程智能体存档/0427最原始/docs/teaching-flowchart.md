# CoursePilot Agent 教学环节作用流程图

下面这张图基于当前项目中定义的工作流与 20 个教学痛点整理，适合用于展示产品在教学全流程中的切入位置。

```mermaid
flowchart LR
    A["输入起点<br/>培养方案 / 课程大纲 / 教材章节 / 班级学情 / 泛雅课程上下文"] --> B["课前准备阶段"]
    B --> B1["课程定位与目标设计<br/>生成课程-章节-课次三级目标"]
    B --> B2["教学内容取舍<br/>识别重难点与推荐讲授顺序"]
    B --> B3["药学场景转化<br/>把管理学概念转成药学案例"]
    B --> B4["学情分析与教学预判<br/>生成前测问卷与差异化策略"]

    B4 --> C["课中实施阶段"]
    C --> C1["教学设计<br/>导入-讲授-互动-练习-总结-作业"]
    C --> C2["PPT与教案起草<br/>输出教案初稿、PPT提纲、课堂话术"]
    C --> C3["教学资源整合<br/>汇总政策、行业、文献、数据素材"]
    C --> C4["课堂提问与互动<br/>生成分层提问、追问脚本、投票题"]
    C --> C5["课堂节奏控制<br/>提供45/90分钟节奏模板与压缩建议"]
    C --> C6["实践教学设计<br/>生成任务书、情境模拟与评价标准"]

    C6 --> D["课后评价与反馈阶段"]
    D --> D1["过程性评价设计<br/>目标映射到任务、Rubric、平时分"]
    D --> D2["作业批改与反馈<br/>初批文本作业、归类错因、生成个性反馈"]
    D --> D3["课程思政与专业融合<br/>识别价值议题并自然嵌入"]
    D --> D4["考试命题与试卷设计<br/>生成题库、组卷并校验覆盖度"]

    D4 --> E["教师发展与课程建设阶段"]
    E --> E1["学科前沿跟踪<br/>追踪政策、行业与文献变化"]
    E --> E2["课后复盘与教学反思<br/>生成结构化复盘报告与改进建议"]
    E --> E3["教学督导与同行评价<br/>预评估教案与示范课风险点"]
    E --> E4["教学团队协作与经验共享<br/>统一标准、共享案例与资源"]
    E --> E5["跨轮次持续优化<br/>沉淀课程知识库与版本迭代记录"]
    E --> E6["课堂管理与参与激励<br/>提供规则模板、激励方案、应对脚本"]

    E6 --> F["输出结果<br/>更高质量的备课 / 更稳定的课堂实施 / 更可追踪的评价反馈 / 可持续积累的课程资产"]

    G["泛雅连接能力"] -. "同步课程、作业、题库、学习数据" .-> B
    G -. "课中发布任务与课后回收数据" .-> D
    G -. "沉淀日志用于复盘和课程建设" .-> E
```

## 展示时可配套的一句话说明

CoursePilot Agent 不是只服务某一个单点任务，而是沿着“课前备课 - 课中实施 - 课后评价 - 持续改进”整条教学链路介入，把新教师最容易卡住的环节串成一个可执行、可反馈、可沉淀的闭环。
