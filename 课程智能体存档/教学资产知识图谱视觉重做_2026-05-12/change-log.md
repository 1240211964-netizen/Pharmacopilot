# Change Log

## Plan

- 归档当前“粒子知识图谱”版本作为改造前。
- 重做 canvas 视觉语言：
  - 降低随机网络感；
  - 使用稳定轨道、分组语义区和更克制的节点层级；
  - 减少画布文字，文字放到右侧说明和 hover tooltip；
  - 优化颜色、线条、背景和卡片质感。
- 保留现有数据聚合、筛选、hover、点击详情、资产详情联动。
- 运行 `node --check 前端核心/app.js`、`npm run build:static`、`npm run build:server`。
- 浏览器检查桌面端和移动端。

## Result

- 已将图谱从随机力导向视觉改为更稳定的语义分区知识星图。
- 默认状态不再高亮所有中枢关系线，只有 hover 或选中具体节点时才强调关系。
- 节点尺寸、颜色、光晕、线条透明度和标签策略均已收敛：默认只保留核心标签，其余信息通过 hover tooltip 和右侧详情查看。
- 图谱布局改为生成材料、导航训练、上传知识库、泛雅记录、课程、标签、来源边界的稳定分区。
- 背景改为纸面式轨道和少量微粒，去掉上一版粗糙网格感。
- 保留数据聚合、筛选、hover、点击详情和资产详情联动逻辑。
- 已通过 `node --check 前端核心/app.js`、`npm run build:static`、`npm run build:server`。
- 已完成桌面端与 `390 x 844` 移动端浏览器检查，无控制台错误。
