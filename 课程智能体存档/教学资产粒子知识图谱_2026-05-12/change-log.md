# Change Log

## Plan

- 在正式改动前归档 `assets.html`、`app.js`、`styles.css` 和 `package.json`。
- 在教学资产页增加“资产知识图谱”区域，用粒子节点和连线表达：
  - 教师在智能体里产生的训练报告、实践材料、Rubric、任务单等数据；
  - 教师上传的课程知识库元数据；
  - 来源边界、标签、课程和复用关系。
- 图谱交互支持悬停/点击查看节点说明，支持类型筛选。
- 保持当前资产上传、资产列表、详情、复制和删除逻辑不被破坏。
- 运行 `node --check 前端核心/app.js`、`npm run build:static`、`npm run build:server`，并做浏览器烟测。

## Result

- 已在 `前端核心/assets.html` 增加“资产知识图谱”模块，放在资产统计之后、上传/详情工作区之前。
- 已在 `前端核心/app.js` 增加前端知识图谱生成逻辑：
  - 从 `collectAssetItems()` 聚合训练报告、实践材料、Rubric、任务、上传知识库元数据、泛雅记录和派生资产；
  - 自动生成数据中枢、资产节点、课程节点、标签节点和来源边界节点；
  - 使用 canvas 粒子网络渲染节点、关系线、悬停提示和点击详情；
  - 支持 `全部 / 智能体生成 / 导航训练 / 上传知识库 / 泛雅记录 / 课程 / 标签 / 来源边界` 筛选；
  - 上传或删除资产后会自动刷新图谱。
- 已在 `前端核心/styles.css` 增加图谱区域、筛选、图例、节点详情和移动端适配样式。
- 浏览器检查发现并修复了空状态提示覆盖 canvas 的问题。
- 已通过 `node --check 前端核心/app.js`、`npm run build:static`、`npm run build:server`。
- 已完成桌面端与 `390 x 844` 移动端浏览器烟测，无控制台错误。
