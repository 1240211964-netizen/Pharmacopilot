## Changes

- Added a right-side `关卡详情` panel inside the game map module.
- Kept the unlocked-assets panel, but moved it below the step detail panel.
- Clicking an unlocked map node now updates `trainingState.currentStepId`, refreshes the map and detail panel, and no longer scrolls to the full training workspace.
- Locked map nodes still show `请先完成前序关卡，再解锁该环节`.
- Added compact in-map option selection for the current step.
- Added in-map confirmation through `confirmGameMapStep()`, reusing the existing `confirmTrainingStep()` scoring and report update logic.
- Added `进入完整训练工作台` as an explicit secondary action for users who need the full editing workspace.
- Added `renderGameMapStepDetail()`, `selectGameMapPrimaryOption()`, and `confirmGameMapStep()` and exposed them on `window` for debugging.
- Added CSS for the map detail card, compact option buttons, advice box, and responsive behavior.
- Updated navigation-page CSS/JS cache query strings to `map-detail-20260508`.
